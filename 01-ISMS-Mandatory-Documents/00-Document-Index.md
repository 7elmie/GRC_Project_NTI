# 01 — ISMS Mandatory Documents: Index

## Scenario Basis

This folder contains the ISO 27001:2022 **mandatory documented information** for the ISMS clauses (4–10). All documents in this project use a single fictional client to keep the documentation set internally consistent:

> **Felex Financial Group (FFG)** — a mid-sized digital banking and payments company, ~450 employees, operating a core banking platform, a payment gateway, corporate IT, and hybrid on-prem/cloud infrastructure. FFG has an existing ISMS and claims ISO 27001:2022 compliance; this project performs the internal audit and documentation review against that claim.

## Documents in this Folder

| # | Document | ISO 27001:2022 Clause | Purpose |
|---|----------|------------------------|---------|
| 1 | ISMS Scope Statement | 4.3 | Defines boundaries and applicability of the ISMS |
| 2 | Information Security Policy | 5.2 | Top-level policy, approved by top management |
| 3 | Information Security Objectives | 6.2 | Measurable ISMS objectives and plans to achieve them |
| 4 | Roles, Responsibilities & Authorities | 5.3 | ISMS governance structure and RACI |
| 5 | Document Control Procedure | 7.5 | Governs creation, review, approval, versioning of all ISMS documents |

## Document Conventions Used Across the Project

- **Status**: Draft / Under Review / Approved
- **Classification**: Internal (all ISMS documents in this project are treated as Internal unless stated otherwise)
- **Owner**: role, not individual name (per good GRC practice — avoids re-issuing documents on staff turnover)
- **Review cycle**: Annually, or upon significant change (org structure, major incident, regulatory change, scope change)
